# welcome message from react

Приветственное сообщение от React.

## Описание проекта / Description of the project

Приложение демонстрирует базовые концепты работы с React, такие как:
- Взаимодействие с пользователем с помощью стандартного окна ввода prompt.
- Использование функциональных компонентов.
- Передача данных между компонентами через пропсы.
- Стиль компонентов через CSS.
- Работа с изображениями в приложении.
При запуске приложение выводит логотип, а также приветственное сообщение с использованием имени пользователя, которое передается в компонент Message через пропсы.

Реализованные функции:
- Запрос имени пользователя: при запуске приложения появляется окно prompt, в котором пользователь вводит свое имя.
- Приветственное сообщение: имя пользователя передается в компонент Message, который отображает сообщение в зеленом цвете с заданным размером шрифта.
- Использование стилей: стили для компонентов задаются в отдельном CSS файле (App.css), а также встроенными стилями для текста.


The application demonstrates the basic concepts of working with React, such as:
- User interaction using the standard prompt input window.
- Use of functional components.
- Data transfer between components via passes.
- Styling of components via CSS.
- Working with images in the application.
At startup, the application displays a logo, as well as a welcome message using the username, which is passed to the Message component via the props.

Implemented functions:
- User Name Request: When the application is launched, a prompt window appears in which the user enters his name.
- Welcome message: The user's name is passed to the Message component, which displays the message in green with the specified font size.
- Using styles: styles for components are set in a separate CSS file (App.css), as well as embedded styles for text.
